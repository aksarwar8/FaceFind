2. **Image selection — `evaluate()`**
   It shuffles all annotation entries with `random.Random(seed)` and takes the first `limit`. The default seed is **42**, and `--seed 42` sets it explicitly. `--limit 0` selects all entries. Sampling is uniform over annotation entries; it does not balance or stratify by face density.

3. **IoU and detection counts — `calculate_iou()` and `evaluate()`**
   `calculate_iou()` computes intersection-over-union from the two boxes’ coordinates. For each readable image, `evaluate()` processes predictions in descending confidence order. Each prediction is matched to the highest-IoU **unmatched** ground-truth box. IoU at or above the configured cutoff (default `0.5`) counts as a true positive; an unmatched prediction is a false positive. Any ground-truth box left unmatched is a false negative. This is greedy, confidence-ordered one-to-one matching.

4. **Metrics — `evaluate()`**
   It calculates aggregate metrics over readable sampled images:
   - precision = TP / (TP + FP)
   - recall = TP / (TP + FN)
   - F1 = harmonic mean of precision and recall

   A zero denominator produces a metric value of `0.0`.

5. **Manifest — `evaluate()` and `validate_manifest_path()`**
   The JSON manifest records dataset paths, seed, requested and actual sample counts, IoU cutoff, model name, detector parameters, counts, metrics, per-image results, unreadable samples, and images left out by the limit. The output path must be inside `data/private/evaluation`, outside the dataset, and must not be a directory or unsafe hard link. The script creates the output directory if needed and writes the manifest. **It can overwrite an existing manifest at the chosen path**, so use a fresh filename.
